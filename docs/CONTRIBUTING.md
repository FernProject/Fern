# Contributing

Fern was initially made by one person (me - along with all the GNU and Linux contributors). This means, it's development will be very slow if there's just one person working on it, updates, and patches will be very slow. That's where open source is a real saviour. If you can see Fern becoming something real, why not be a part of that? With contributors help, I believe this operating system can become great, and maybe get some real recognition.

## Why Contribute?

If you look through our source, or use a Fern ISO, and think of something really cool, and impactful you could add (or find the way we do something annoying, and want to change it), do it! Fork the repo, and add your changes. We're always looking for new functionality.

Similarly, if you run into an issue, make an [issue ticket](https://github.com/fernproject/fern/issues). If you see any issues, and know how to fix them, do it!!! It really helps, more than you'd think.

## Think First

Before you make a pull request, ask yourself these questions:

* Why am I adding this?
* Will this make help people?
* Will this advance the development of Fern?

Self reflection is always important, impulsivity leads to mistakes.
